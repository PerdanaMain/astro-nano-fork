### Key Responsibilities

- Build authentication system, authorization and connect to MySQL database.
- Build the report feature to generate the report of the asset.
- Build the dashboard to see the overview of the asset.
- Error handling and logging.
- Testing and documentation.

### Features

- Authentication, to access the features that need to be authenticated.
- Dashboard, to see the overview of the application.
- Farming Management, to manage the farming process from planting to harvesting.
- Report, to generate the report of the farming process.
