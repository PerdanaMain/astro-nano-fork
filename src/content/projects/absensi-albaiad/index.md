Absensi Albaiad is a presence management system for Albaiad Students and Teachers. This system is built to support the Albaiad Islamic School in managing the presence of the students, reporting the activities of the students and give the parents a way to see the presence of their children.

### Key Responsibilities

- Design the database schema and implement the database using MySQL.
- Implementing the business logic for the feature using Laravel.
- Build Role Based Access Control (RBAC) for the feature.
- Implementing the authentication and authorization for the feature.
- Handle the file upload and storage using Cloudinary.
- Build the reporting and analytics for the feature.
