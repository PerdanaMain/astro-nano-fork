Dynamits is a package tracking system for electrical vehicles, designed to streamline the process of tracking and managing packages. It provides a comprehensive solution for users to monitor their packages in real-time, ensuring efficient delivery and management.
visit the page [here](https://dynamits.id/).

### Key Responsibilities

- Design the database schema and implement the database using PostgreSQL.
- Develop the API using Node.js and Express.js.
- Implement the authentication and authorization using JWT.
- Implement real-time tracking of the packages using WebSockets.
- Deploy the application using Docker and Nginx.

### Features

- Real-time package tracking.
- User authentication and authorization.
- API for package management.
- API for user management.
- API for vehicle management.
