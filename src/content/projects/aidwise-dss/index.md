Aidwise DSS is a decision support system for people in Manyar, Gresik, East Java. This system is built to support the people in Manyar, Gresik, East Java in support system for giving the Bantuan Langsung Tunai (BLT) for deserving people. This system using AHP and WP Method for decision making.

### Key Responsibilities

- Design the database schema and implement the database using MySQL.
- Collect the data such as Criteria and Alternatives.
- Build the AHP and WP Method for decision making.
- Build the report and dashboard for the system.
