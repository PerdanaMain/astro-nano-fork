AMDK Santri is a comprehensive business management system designed specifically for Air Minum Dalam Kemasan Santri, a bottled water distribution company. The system streamlines and automates various business operations to enhance efficiency, accuracy, and decision-making capabilities. The primary purpose of AMDK Santri is to digitize and integrate all core business processes into a single, cohesive system. This integration enables better control over operations, improved resource management, and enhanced business intelligence capabilities.

### Key Responsibilities

- Design the database schema and implement the database using MySQL.
- Implementing the business logic for the feature using Laravel.
- Build Role Based Access Control (RBAC) for the feature.
- Implementing the authentication and authorization for the feature.
- Handle the file upload and storage using Cloudinary.
- Build the reporting and analytics for the feature.
