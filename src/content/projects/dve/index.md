### Key Responsibilities

- Build the authentication system, authorization and connect to MongoDB database.
- Build the dashboard to see the overview of the application.
- Build the feature to validate the network device.
- Build the feature to generate the report of the network device.
- Build the feature to manage the network device.
- Build the feature to manage the user.

### Features

- Authentication, to access the features that need to be authenticated.
- Dashboard, to see the overview of the application.
- Network Device Management, to manage the network device of In Building PT XL Axiata Surabaya.
- Report, to generate the report of the network device.
- User Management, to manage the user of the application.
