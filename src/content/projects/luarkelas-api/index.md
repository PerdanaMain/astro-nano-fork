Luarkelas is an Indonesia edutech startup that provides an online learning platform for students. The main purpose of this project is to build an API Architecture for Luarkelas Indonesia Edutech Startup business. Provide the database schema design, business logic, authentication system, unit testing, error handling, and API documentation.
visit the site [Luarkelas](https://luarkelas.id)

### Key Responsibilities

- Build and implement the system architecture and business logic for Luarkelas API
- Handle the database schema design and implementation
- Build and implement the authentication and authorization system
- Implement Unit Testing to ensure the API is working properly
- Implement Error Handling to ensure the API is robust and reliable
- Implement API Documentation using Swagger
- API Deployment
