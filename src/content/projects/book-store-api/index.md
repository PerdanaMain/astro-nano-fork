An API Architecture for Book Store Application By Sanber Code Bootcamp Final Project. This API is used to manage book data from manage order, transaction and history. The main purpose of this project is to implement the knowledge and skills that have been learned in the Sanber Code Bootcamp start from design, development, testing and deployment.

### Key Responsibilities

- Build and implement the system architecture and business logic for Book Store API
- Handle the database schema design and implementation
- Build and implement the authentication and authorization system
- Implement Unit Testing to ensure the API is working properly
- Implement Error Handling to ensure the API is robust and reliable
- Implement API Documentation using Swagger
- API Deploy Implementation using Vercel

### Features

- Authentication
- Authorization
- Book Management
- Order Management
- Transaction Management
